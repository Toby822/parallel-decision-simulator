# Parallel: recording guide

Target length: **2 minutes 20 seconds**. Record the actual running app. Reset the example first; use seed 42, 10,000 worlds and 36 months. Turn spoken responses on if they work in the recording browser; typed commands are a reliable fallback. Do not wait for both full narration and the same full spoken answer.

| Time | Show | Say |
| --- | --- | --- |
| 0:00–0:15 | Full dashboard, then the two salaries | “The London job pays £850 more a month. That looks like the obvious choice. But the offer is only one number in a much bigger decision.” |
| 0:15–0:35 | Savings bands and the London-ahead fraction | “This is Parallel. It puts both choices through the same 10,000 possible futures: the same inflation, unexpected bills and employment-shock draws. Under these example assumptions, London finishes ahead in about 24% of worlds.” |
| 0:35–0:55 | Ask “Show me the downside” | “I can ask the simulated Alexa+ experience to explain the downside. It answers from the calculation, and I can inspect the tool action. These are conditional scenarios, not forecasts about a real person.” |
| 0:55–1:15 | Ask “What would change my mind?” | “The useful part is what could change the answer. Here the London rent tipping point is about £1,607 a month. That gives me a concrete question to take to a landlord.” |
| 1:15–1:35 | Ask “Lower London rent by £200” | “Now change one assumption. The same shocks run again, and London’s average cash result becomes positive. It finishes ahead in about 94% of these worlds. The voice interaction is changing the model, not adding commentary to a fixed chart.” |
| 1:35–1:55 | Set time value to £20/hour, then point at cash chart | “Money is still only part of it. If I value the extra commute time at £20 an hour, the comparison changes again. The cash savings chart stays separate, so my preferences are visible.” |
| 1:55–2:20 | Ask “Undo,” inspect one world, export the run | “The simulation runs in Python locally, with a verified browser port for this demo. I can undo changes and export every assumption, seed and result. Parallel gives me a way to test a decision before I have to live with it.” |

## Reference values

These values were generated by the Python engine, not chosen for narration.

| Configuration | London ahead | Average London cash difference | Average time-adjusted difference |
| --- | ---: | ---: | ---: |
| Default: rent £1,650, time £0/hour | 23.90% | −£1,593 | −£1,593 |
| Rent £1,450, time £0/hour | 94.35% | +£5,825 | +£5,825 |
| Rent £1,450, time £20/hour | 0.00% in this run | +£5,825 | −£5,695 |

The final row is a result within the model, not a statement that the true real-world probability is zero. The extra commute is 16 hours/month × 36 months × £20 = £11,520 of stated time preference.
